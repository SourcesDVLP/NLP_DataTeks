## Deskripsi
Preprocessing teks pada dataset ulasan e-commerce berbahasa Indonesia
([dipawidia/ecommerce-product-reviews-sentiment](https://huggingface.co/datasets/dipawidia/ecommerce-product-reviews-sentiment)).

Tahapan: case folding, cleaning, tokenisasi, stopword removal, dan stemming (Sastrawi).
